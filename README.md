# Idea Tracker

An application for tracking and managing ideas.

## Project Structure

- `backend/` - Express + TypeScript REST API

## Getting Started

### Backend Setup
1. Navigate to the `backend` directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
